PERSONAL PORTFOLIO WEBSITE
=========================
Files:
- index.html       Main page with Home, About, Services and Contact sections
- css/style.css    External stylesheet
- js/script.js     Form feedback and current-year interaction
- images/          Place your own image assets here if you add any

HOW TO RUN:
1. Extract this folder.
2. Open index.html in a browser.
3. Internet access is required for Bootstrap and Google Fonts CDN resources.

CUSTOMIZE:
Replace the demo name "Alex Morgan", descriptions, skills and contact details with your own information.
The contact form is a front-end demo only; it does not send email or store submissions.
